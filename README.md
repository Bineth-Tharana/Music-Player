# 🎵 Music Player

A simple and responsive Music Player built using HTML, CSS and JavaScript. This application allows users to play, pause, skip and navigate through songs with an attractive user interface and smooth user experience.

## 🚀 Live Demo
https://bineth-tharana.github.io/Music-Player/

## 📌 Features

* ▶️ Play and Pause music
* ⏭️ Next and Previous track controls
* 🎵 Dynamic song information display
* 📊 Progress bar with real-time updates
* ⏱️ Song duration and current time tracking
* 📱 Responsive design for different screen sizes
* 🎨 Modern and user-friendly interface

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsive design
* **JavaScript (ES6)** – Music player functionality and interactivity

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/Bineth-Tharana/Music-Player.git
```

2. Navigate to the project directory:

```bash
cd Music-Player
```

3. Open `index.html` in your browser.

## 🎮 How to Use

1. Open the application in your browser.
2. Click the **Play** button to start playing music.
3. Use the **Next** and **Previous** buttons to switch tracks.
4. Drag the progress bar to seek a specific position in the song.
5. Adjust the volume using the volume slider.
